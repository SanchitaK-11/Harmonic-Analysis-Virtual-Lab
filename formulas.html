Introduction to Harmonic Analysis

• Harmonic Analysis is a mathematical technique used to study periodic functions and signals.

• It breaks complex waveforms into simple sine and cosine components called harmonics.

• It is mainly based on the concept of Fourier Series.

• Harmonic analysis is widely used in signal processing, communication systems, sound engineering, and electrical circuits.

• It helps in understanding frequency, amplitude, and behavior of periodic signals accurately.

Periodic Function

A function is periodic if:

f(x + T) = f(x)

where T is the period of the function.

T = 2L

2L = b-a

Where,
b = Last value of x when function becomes periodic.
a = First value of x.

  • sin(x) → period = 2π
  • cos(x) → period = 2π
  • tan(x) → period = π

Harmonic Series

f(x) = a₀/2 + Σ (aₙ cos(nπx/L) + bₙ sin(nπx/L))

Harmonic series expresses a periodic function as a combination of sine and cosine terms.

Harmonic Coefficients

N = Number of distinct Experiments or Observations.

n = Number of Harmonic

a0 → average value of signal

aₙ → cosine (even) harmonics

bₙ →sine (odd) harmonics



a₀ = (2/N) Σ (y)
aₙ = (2/N) Σ(y cos(nπx/L))
bₙ = (2/N) Σ(y sin(nπx/L))

Harmonic Interpretation

For first Harmonic,n = 1

f(x) = a₀/2 + a1 cos(πx/L) + b1 sin(πx/L)

Amplitude of first Harmonic

Amp = √(a1​² + b1²)

For second Harmonic,n = 2

f(x) = a₀/2 + a1 cos(πx/L) + b1 sin(πx/L) + a2 cos(2πx/L) + b2 sin(2πx/L)

Amplitude of second Harmonic

Amp = √(a2² + b2²)

Key Points

  • Periodic functions repeat after fixed intervals.
  • Fourier series uses sine and cosine waves.
  • Harmonic analysis is important in signal processing.
  • Cosine terms represent even functions.
  • Sine terms represent odd functions.
