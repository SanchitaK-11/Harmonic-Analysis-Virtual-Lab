1. Calculating a₁ (T = 6)

Determine the value of a₁ for the following tabulated data:

x012345
y91824282620
cos πx/311/2-1/2-1-1/21/2
(A) -8.33
(B) -7.14
(C) -4.16
(D) 0
View Step-by-Step Solution
Formula: a₁ = (2/N) Σ(y · cos πx/3) where N = 6.
Summation:
(9 × 1) + (18 × 0.5) + (24 × -0.5) + (28 × -1) + (26 × -0.5) + (20 × 0.5)
= 9 + 9 - 12 - 28 - 13 + 10 = -25
Final Result: a₁ = (2/6) × -25 = 1/3 × -25 = -8.333

Example 5. Comprehensive Analysis

Find the first harmonic coefficients for the following data (Period = 2π):

x (rad)0π/32π/3π4π/35π/3
y1.981.301.051.30-0.88-0.25
a₁ = 0.5
a₁ = 0.373, b₁ = 1.004
b₁ = 0.85
None of these
View Description & Solution
Step 1: Identify Parameters
Number of intervals (N) = 6. Step interval = 60° (π/3 radians).
Multipliers for a₁ are cos(x): [1, 0.5, -0.5, -1, -0.5, 0.5].
Multipliers for b₁ are sin(x): [0, 0.866, 0.866, 0, -0.866, -0.866].
Step 2: Detailed a₁ Calculation [ Σ(y · cos x) ]
• x = 0: 1.98 × 1.0 = 1.98
• x = π/3: 1.30 × 0.5 = 0.65
• x = 2π/3: 1.05 × (-0.5) = -0.525
• x = π: 1.30 × (-1.0) = -1.30
• x = 4π/3: -0.88 × (-0.5) = 0.44
• x = 5π/3: -0.25 × 0.5 = -0.125
Summation Σ = 1.98 + 0.65 - 0.525 - 1.30 + 0.44 - 0.125 = 1.12
a₁ = (2/6) × 1.12 = 1.12 / 3 = 0.3733
Step 3: Detailed b₁ Calculation [ Σ(y · sin x) ]
• x = 0: 1.98 × 0 = 0
• x = π/3: 1.30 × 0.866 = 1.1258
• x = 2π/3: 1.05 × 0.866 = 0.9093
• x = π: 1.30 × 0 = 0
• x = 4π/3: -0.88 × (-0.866) = 0.7621
• x = 5π/3: -0.25 × (-0.866) = 0.2165
Summation Σ = 0 + 1.1258 + 0.9093 + 0 + 0.7621 + 0.2165 = 3.0137
b₁ = (2/6) × 3.0137 = 3.0137 / 3 = 1.0046
