Fourier Series: f(x)= a₀/2 + Σ(an cos(nx) + bn sin(nx))
an = (2/N) Σ(y cos(nπx/L))
bn = (2/N) Σ(y sin(nπx/L))
a₀ = (2/N) Σy
Harmonic Amplitude: Amp = √(an² + bn²)
Phase Angle: θ = tan⁻¹(bn/an)
Frequency = n / T
Wave Function: y = A sin(ωt + φ)
Angular Frequency: ω = 2πf
